# 「続けたもん勝ち」というカフカが大切にしている考え方について話します。

学び続けたもんがち。

覚悟決めて金燃やし投資し続けられたもん勝ち。

動き続けたもん勝ち。

商品作り続けたもん勝ち。

渾身のローンチをし続けられたもん勝ち。

言い訳せず、

闘志燃やし続けて、

負けん気出し続けて、

何くそ精神で突き進み続けることができたもん勝ち。

何もかも、「続けたもん勝ち」な世界。

本当にそう思う。

❏━━━━━━━━━━━━━━━❏

いつもいつも、周りは消えていった。

❏━━━━━━━━━━━━━━━❏

最初は一緒にがんばろうぜと、ノリが合っていても、だんだん周りはノリが変わって、消えていった。

3年前一緒にビジネスで成功しようぜ頑張ろうぜって話してたあいつは、今就活で忙しそうにしてる。

5年前一緒に世界旅しようぜと言ったあいつは、平凡な暮らしができればいいやと言っている。

今ふと思ったけど、数ヶ月前とかまでは、こういった昔の友達の変化を見て、悲しくなっていたけど、最近は悲しくならない。なんでだろうと考えてみたら、今が1番楽しいからかもしれない。

自分の周りには最高の仲間がたくさんいる。

他のポストでも話したことあるけど、私は今、

❏━━━━━━━━━━━━━━━❏

ワンピースでいう「大船団」

キングダムでいう楊端和率いる「山の民」

みたいな最強の集団をつくるのを目標にしている。

❏━━━━━━━━━━━━━━━❏

で、だんだんそれが形になってきている。

秘書軍団と、生徒や仲間との軍団が、みなかなり優秀になってきていて、上の人脈もかなりついてきた。

続けてきた結果、こんな素晴らしい仲間なり人脈なり、夢を手にできた。

本当に、今が1番楽しい。

めっちゃしんどい時も正直あった。

何も上手く行かなくて、自信を極端になくした時もあった。

けど、どうしても人生を変えたかったから私は続けた。

消えていく友人を見ながら、悲しい気持ちになりながら、ひとり続けた。

そうしたら今になった。

人生で1番楽しい、幸せな今を手に入れた。

もっともっと最高に幸せで刺激的な人生を手にしたいから、まだまだ続ける。

❏━━━━━━━━━━━━━━━❏

「狂気と継続力」（今度ちゃんと解説する）

「大船団」

まだまだおもしろいものを見せていきます。

楽しみにしていてください。

話いろいろ変わった感じしましたが、重要なのは、「続けること」「継続すること」です。

さっきちらっと書きましたが、
