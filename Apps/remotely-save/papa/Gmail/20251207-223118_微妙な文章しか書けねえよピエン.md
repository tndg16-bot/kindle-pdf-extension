# 微妙な文章しか書けねえよピエン

あーこの文章微妙かもな。と思いながらどんどん書き進めていると、

案外これええやんという文章ができる。

これあるあるです。マジであるある。

だから、とにかく書き始めろって思います。

文章の出だしの部分で死ぬほど迷って、書いては消して、書いては消してを繰り返しまくっている優柔不断ちゃんが多いですが、

そのままどんどん書いていけば、案外それなりに良い文章ができあがったりします。

もちろんマジで意味わからん支離滅裂な文章ができることも初心者にはあるかと思います。

が、迷って何もかけていないよりは圧倒的にマシなわけです。

どんどん書いて、クソ下手な文章をどんどん生み出していきましょう。それをやっていけばどんどんライティングも磨かれていきます。

❏━━━━━━━━━━━━━━━❏

”迷わず書き始めて”

”迷わず書き終えるまでタイピングを進める”

ってのが大事です。

❏━━━━━━━━━━━━━━━❏


マジでこれだけ意識してとにかく書きまくってみてください。
