# Google Cloud Platform 完全設定ガイド（ゼロからの手順）

タスク管理ツールで Google Calendar/Tasks API を使用するための、**完全な設定手順**です。
すべての手順を順番に実行してください。

---

## 📌 事前準備

### 必要なもの
- ✅ Googleアカウント（Gmail等）
- ✅ Chrome ブラウザ（推奨）
- ✅ インターネット接続

---

## 手順 1: Google Cloud Console にアクセス

### 1-1. ブラウザで開く
1. Chrome ブラウザを開きます
2. 以下のURLにアクセスします:
   ```
   https://console.cloud.google.com/
   ```

### 1-2. Googleアカウントでログイン
- まだログインしていない場合、Googleアカウントでログインします
- 普段使っているGmailアカウントでOKです

### 1-3. 初回アクセス時
- 「利用規約」が表示されたら、内容を確認して「同意して続行」をクリック

---

## 手順 2: プロジェクトの作成

### 2-1. プロジェクト選択画面を開く
1. 画面上部、Google Cloud Platform ロゴの右側に「プロジェクトを選択」というドロップダウンがあります
2. そこをクリックします

**見つからない場合**:
- 画面左上のハンバーガーメニュー（三本線）をクリック
- または、直接以下のURLにアクセス:
  ```
  https://console.cloud.google.com/projectcreate
  ```

### 2-2. 新しいプロジェクトを作成
1. 「新しいプロジェクト」ボタンをクリック
2. 以下の情報を入力します:

   | 項目 | 入力内容 |
   |------|----------|
   | **プロジェクト名** | `Task Manager`（または任意の名前） |
   | **組織** | 「組織なし」のままでOK |
   | **場所** | 「組織なし」のままでOK |

3. 「**作成**」ボタンをクリック
4. プロジェクト作成には数秒かかります（画面右上に通知が表示されます）

### 2-3. プロジェクトが作成されたことを確認
- 画面上部のプロジェクト名が「Task Manager」になっていることを確認
- まだなっていない場合は、プロジェクト選択ドロップダウンから「Task Manager」を選択

---

## 手順 3: API の有効化

### 3-1. API ライブラリ画面を開く

**方法1: メニューから**
1. 画面左上のハンバーガーメニュー（三本線）をクリック
2. 「API とサービス」にマウスを乗せる
3. 「**ライブラリ**」をクリック

**方法2: 直接URLにアクセス**
```
https://console.cloud.google.com/apis/library
```

### 3-2. Google Calendar API を有効化

1. 検索ボックスに「**Google Calendar API**」と入力
2. 検索結果から「**Google Calendar API**」をクリック
3. 「**有効にする**」ボタンをクリック
4. 数秒待つと、「API が有効です」と表示されます

### 3-3. Google Tasks API を有効化

1. 左上の「←」（戻る）ボタンをクリックして、ライブラリ画面に戻る
   - または、再度 https://console.cloud.google.com/apis/library にアクセス
2. 検索ボックスに「**Google Tasks API**」と入力
3. 検索結果から「**Google Tasks API**」をクリック
4. 「**有効にする**」ボタンをクリック
5. 数秒待つと、「API が有効です」と表示されます

### ✅ 確認
- 「API とサービス」→「有効な API とサービス」で、以下の2つが表示されていればOK:
  - Google Calendar API
  - Google Tasks API

---

## 手順 4: OAuth 同意画面の設定

### 4-1. OAuth 同意画面を開く

**方法1: メニューから**
1. 画面左上のハンバーガーメニュー（三本線）をクリック
2. 「API とサービス」にマウスを乗せる
3. 「**OAuth 同意画面**」をクリック

**方法2: 直接URLにアクセス**
```
https://console.cloud.google.com/apis/credentials/consent
```

### 4-2. User Type を選択

1. 「**User Type**」で「**外部**」を選択
   - ※個人のGoogleアカウントで使用する場合は「外部」を選択します
2. 「**作成**」ボタンをクリック

### 4-3. アプリ情報を入力（ステップ1）

以下の項目を入力します:

| 項目 | 入力内容 | 必須 |
|------|----------|------|
| **アプリ名** | `Task Manager`（または任意の名前） | ✓ |
| **ユーザーサポートメール** | あなたのGmailアドレス | ✓ |
| **アプリのロゴ** | （スキップ可） | |
| **アプリドメイン** | （すべてスキップ可） | |
| **承認済みドメイン** | （スキップ可） | |
| **デベロッパーの連絡先情報** | あなたのGmailアドレス | ✓ |

入力したら、画面下部の「**保存して次へ**」をクリック

### 4-4. スコープを追加（ステップ2）

1. 「**スコープを追加または削除**」ボタンをクリック
2. 右側にスライドパネルが開きます
3. 検索ボックスに「**calendar**」と入力
4. 以下のスコープを探して、**チェックを入れます**:
   ```
   .../auth/calendar.events
   ```
   - 説明: 「カレンダー イベントの表示、編集...」
   - スコープ種類: 「機密」

5. 次に、検索ボックスに「**tasks**」と入力
6. 以下のスコープを探して、**チェックを入れます**:
   ```
   .../auth/tasks
   ```
   - 説明: 「タスクの作成、編集...」
   - スコープ種類: 「機密」

7. **2つのスコープにチェックが入っていることを確認**
8. 画面下部の「**更新**」ボタンをクリック
9. スコープ一覧に2つ表示されていることを確認
10. 「**保存して次へ**」をクリック

### 4-5. テストユーザーを追加（ステップ3）

1. 「**+ ADD USERS**」ボタンをクリック
2. ポップアップが表示されるので、あなたのGmailアドレスを入力
   - 例: `your.email@gmail.com`
3. 「**追加**」ボタンをクリック
4. テストユーザー一覧にあなたのメールアドレスが表示されます
5. 「**保存して次へ**」をクリック

### 4-6. 概要を確認（ステップ4）

1. 設定内容が表示されます
2. 内容を確認して、「**ダッシュボードに戻る**」をクリック

---

## 手順 5: OAuth クライアント ID の作成

### 5-1. 認証情報画面を開く

**方法1: メニューから**
1. 画面左上のハンバーガーメニュー（三本線）をクリック
2. 「API とサービス」にマウスを乗せる
3. 「**認証情報**」をクリック

**方法2: 直接URLにアクセス**
```
https://console.cloud.google.com/apis/credentials
```

### 5-2. OAuth クライアント ID を作成

1. 画面上部の「**+ 認証情報を作成**」ボタンをクリック
2. ドロップダウンから「**OAuth クライアント ID**」を選択

### 5-3. アプリケーション情報を入力

| 項目 | 入力内容 |
|------|----------|
| **アプリケーションの種類** | 「**ウェブ アプリケーション**」を選択 |
| **名前** | `Task Manager - Local`（または任意の名前） |

### 5-4. 承認済みのリダイレクト URI を設定

#### JavaScript 生成元を追加
1. 「**承認済みの JavaScript 生成元**」セクションを探す
2. 「**+ URI を追加**」をクリック
3. 以下のURLを入力:
   ```
   http://localhost:5173
   ```

#### リダイレクト URI を追加
1. 「**承認済みのリダイレクト URI**」セクションを探す
2. 「**+ URI を追加**」をクリック
3. 以下のURLを入力:
   ```
   http://localhost:5173
   ```

> **注意**: デプロイ後に本番URLも追加する必要があります（後で追加可能）

### 5-5. 作成を完了

1. すべて入力したら、画面下部の「**作成**」ボタンをクリック
2. 数秒待つと、認証情報が作成されます

## 手順 6: Client ID の取得と保存

### 6-1. Client ID をコピー

作成が完了すると、以下のポップアップが表示されます:

```
OAuth クライアントを作成しました
```

**表示される情報**:
- ✅ **クライアント ID**: `XXXXX.apps.googleusercontent.com`
- ✅ **クライアント シークレット**: `XXXXX-XXXXX-XXXXX`

### 6-2. 情報を保存

**重要**: 以下の2つの情報を **安全な場所にコピー** してください:

1. **クライアント ID（Client ID）**
   - 例: `123456789-abcdefg.apps.googleusercontent.com`
   - この情報はコード内で使用します

2. **クライアント シークレット（Client Secret）**
   - 例: `GOCSPX-XXXXXXXXXXXXX`
   - フロントエンドのみのアプリでは使用しない場合もありますが、念のため保存

**保存方法**:
- テキストファイルにコピー（例: `credentials.txt`）
- パスワードマネージャーに保存
- **絶対にGitにpushしないこと**（`.env`ファイル等で管理）

### 6-3. 後で確認する方法

もしポップアップを閉じてしまった場合:
1. 「API とサービス」→「認証情報」画面を開く
2. 「OAuth 2.0 クライアント ID」セクションに作成した認証情報が表示されます
3. クライアント名をクリックすると、Client ID と Client Secret を確認できます

## 手順 7: APIキーの作成（オプション）

一部のGoogle APIライブラリでは、Discovery Document読み込みにAPIキーが必要な場合があります。

### 7-1. APIキーを作成

1. 「API とサービス」→「認証情報」画面を開く
2. 画面上部の「**+ 認証情報を作成**」ボタンをクリック
3. 「**API キー**」を選択
4. APIキーが自動生成されます

### 7-2. APIキーを制限（推奨）

セキュリティのため、APIキーに制限をかけます:

1. 生成されたポップアップで「**キーを制限**」をクリック
2. 「**アプリケーションの制限**」で「**HTTP リファラー**」を選択
3. 「**ウェブサイトの制限**」で「**項目を追加**」をクリック
4. 以下を追加:
   ```
   http://localhost:5173/*
   ```
5. 「**API の制限**」で「**キーを制限**」を選択
6. 以下の2つのAPIを選択:
   - Google Calendar API
   - Google Tasks API
7. 「**保存**」をクリック

### 7-3. APIキーをコピー

- 認証情報画面で、作成したAPIキーをコピーして安全な場所に保存

## 🆘 トラブルシューティング

### Q1. プロジェクト選択ドロップダウンが見つからない
**A**: 画面左上のハンバーガーメニュー（三本線）をクリック → 「ホーム」を選択すると、プロジェクト選択画面が表示されます。

### Q2. 「API を有効にする」ボタンが表示されない
**A**: すでに有効化されている可能性があります。「管理」ボタンが表示されていれば、APIは有効です。

### Q3. OAuth 同意画面で「外部」が選択できない
**A**: Google Workspace アカウントの場合、管理者権限が必要な場合があります。個人のGmailアカウントを使用してください。

### Q4. スコープが見つからない
**A**:
- 検索ボックスに「calendar」「tasks」と入力して検索
- APIが有効化されていることを確認（手順3）
- ページを更新してから再試行

### Q5. Client ID を紛失した
**A**:
1. 「API とサービス」→「認証情報」を開く
2. OAuth 2.0 クライアント ID セクションで、作成した認証情報をクリック
3. Client ID と Client Secret を再確認できます
