# Google Calendar API 設定ガイド

タスク管理ツールを使用するために、Google Cloud Platform (GCP) での設定が必要です。以下の手順に従って、認証情報を取得してください。

## 手順 1: プロジェクトの作成

1. [Google Cloud Console](https://console.cloud.google.com/) にアクセスします。
2. 左上のプロジェクト選択ドロップダウンをクリックし、「**新しいプロジェクト**」を選択します。
3. プロジェクト名（例: `Task Manager`）を入力し、「**作成**」をクリックします。

## 手順 2: APIの有効化

1. 作成したプロジェクトが選択されていることを確認します。
2. 左側のメニューから「**API とサービス**」>「**ライブラリ**」を選択します。
3. 以下の2つのAPIを検索し、それぞれ「**有効にする**」をクリックします：
   - **Google Calendar API**
   - **Google Tasks API** （ToDoリスト用）

## 手順 3: OAuth 同意画面の設定

1. 左側のメニューから「**API とサービス**」>「**OAuth 同意画面**」を選択します。
2. User Type で「**外部**」を選択し、「**作成**」をクリックします。
   - ※個人のGoogleアカウントでテストする場合は「外部」になります。
3. **アプリ情報**:
   - アプリ名: `Task Manager` など
   - ユーザーサポートメール: あなたのメールアドレス
   - デベロッパーの連絡先情報: あなたのメールアドレス
4. 「**保存して次へ**」をクリックします。
5. **スコープ**:
   - 「**スコープを追加または削除**」をクリックします。
   - 以下のスコープを検索してチェックを入れます：
     - `.../auth/calendar.events` (カレンダー イベントの表示、編集...)
     - `.../auth/tasks` (タスクの作成、編集...)
   - 「**更新**」をクリックし、「**保存して次へ**」をクリックします。
6. **テストユーザー**:
   - 「**ADD USERS**」をクリックし、テストに使用するあなたのGoogleメールアドレスを追加します。
   - 「**保存して次へ**」をクリックします。

## 手順 4: 認証情報の作成

1. 左側のメニューから「**API とサービス**」>「**認証情報**」を選択します。
2. 上部の「**認証情報を作成**」をクリックし、「**OAuth クライアント ID**」を選択します。
3. **アプリケーションの種類**: 「**ウェブ アプリケーション**」を選択します。
4. **名前**: `Localhost` など
5. **承認済みの JavaScript 生成元**:
   - `URI を追加` をクリック
   - `http://localhost:5173` と入力
6. **承認済みのリダイレクト URI**:
   - `URI を追加` をクリック
   - `http://localhost:5173` と入力
7. 「**作成**」をクリックします。

## 手順 5: Client ID の取得

作成が完了すると、「**クライアント ID**」と「**クライアント シークレット**」が表示されます。
**この「クライアント ID (Client ID)」と「APIキー (API Key)」を控えておいてください。**

> [!NOTE]
> クライアントシークレットは、今回はフロントエンドのみのアプリなので使用しない場合がありますが、念のため控えておいてください。
> APIキーが必要な場合は、「認証情報を作成」>「APIキー」から作成できます（Discovery Docの読み込み等に必要な場合があります）。

設定は以上です！完了したら教えてください。
