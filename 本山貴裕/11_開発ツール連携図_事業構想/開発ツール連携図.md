## 🎛 GitHubプロジェクト管理

### 管理体制
- **管理者**: 1人（あなた）
- **AIエージェント**: 複数（Antigravity, Claude Code, Codex CLI, Gemini CLI）

### GitHub Actions CI
PRが作成されるとLint/Buildが自動実行され、失敗するとマージがブロックされます。

```mermaid
flowchart LR
    PR[PR作成] --> CI{GitHub Actions}
    CI -->|Lint OK| Build{Build}
    Build -->|成功| Merge[マージ可能]
    CI -->|Lint NG| Block[❌ マージ拒否]
    Build -->|失敗| Block
```

### 主要ファイル
| ファイル | 用途 |
|---------|------|
| `.github/workflows/ci.yml` | Lint/Build自動チェック |
| `.github/CODEOWNERS` | 重要ファイルの保護 |
| `.github/ISSUE_TEMPLATE/ai_task.yml` | AI向けタスクテンプレート |
| `.github/pull_request_template.md` | PR記述テンプレート |

## 🤖 マルチエージェント階層構造

```mermaid
flowchart TB
    subgraph Human["👤 管理者"]
        H[大きな目標を伝える]
    end

    subgraph MainAgent["🎖 PM: Antigravity"]
        MA[タスク分解・Issue作成・PRレビュー]
    end

    subgraph SubAgents["🛠 実装担当"]
        SA1[Claude Code]
        SA2[Codex CLI]
        SA3[Gemini CLI]
    end

    H --> MA
    MA -- "Issue割り当て" --> SA1
    MA -- "Issue割り当て" --> SA2
    MA -- "Issue割り当て" --> SA3
    SA1 -- "PR" --> MA
    SA2 -- "PR" --> MA
    SA3 -- "PR" --> MA
```

### ワークフロー
1. 管理者 → Antigravity に目標を伝える
2. Antigravity → タスク分解し GitHub Issue を作成
3. サブエージェント → Issue を確認し作業実行
4. サブエージェント → PR を作成
5. GitHub Actions → 自動チェック
6. Antigravity → レビュー・マージ・完了報告
