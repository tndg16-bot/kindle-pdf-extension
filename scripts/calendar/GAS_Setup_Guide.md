# 📅 Google Calendar Reminder Setup Guide

このガイドは、毎日決まった時間に「自己分析ワーク」のリマインダー通知をGoogleカレンダーに自動作成するための設定手順です。

## 手順

1.  **Google Apps Script を開く**
    *   ブラウザで [script.google.com](https://script.google.com/home) にアクセスします。
    *   「新しいプロジェクト」をクリックします。

2.  **コードの貼り付け**
    *   エディタ画面が開くので、既存のコード（`function myFunction()...`）をすべて削除します。
    *   `scripts/calendar/setup_reminders.js` の中身をすべてコピーし、エディタに貼り付けます。

3.  **プロジェクトの保存**
    *   画面上の「無題のプロジェクト」をクリックし、「SelfAnalysisReminder」など適当な名前を付けて保存します。

4.  **スクリプトの実行**
    *   ツールバーの関数選択プルダウン（「デバッグ」の左）から **`setupDailyReminders`** を選びます。
    *   「実行」ボタンを押します。

5.  **権限の承認**
    *   初回のみ、「承認が必要です」というポップアップが出ます。
    *   「権限を確認」 → Googleアカウントを選択 → 「詳細」 → 「SelfAnalysisReminder（安全ではないページ）に移動」 → 「許可」の順に進んでください。
        *   ※「安全ではない」と出ますが、自分で作ったスクリプトなので安全です。

6.  **完了確認**
    *   実行ログに「✅ Setup Complete」と表示されれば成功です。
    *   Googleカレンダーを確認してください。今日の分（すでに過ぎた時間は除く）および、明日以降の毎日のイベントとしてリマインダーが登録されます。

---
**設定を変更したい場合**:
*   時間を変えたいときは、コード内の `EVENTS` リスト（`time: "08:00"` など）を書き換えて、再度 `setupDailyReminders` を実行してください。
