## 🔑 APIキーの設定

### 1. Groq API Key（必須 - 文字起こし用）
1. [Groq Console](https://console.groq.com/keys)にアクセス
2. アカウント作成（無料）
3. 「Create API Key」でキーを作成
4. `gsk_...`で始まるキーをコピー
5. アプリの上部「APIキー設定」で入力

### 2. Google AI Studio API Key（必須 - OCR用）
1. [Google AI Studio](https://aistudio.google.com/app/apikey)にアクセス
2. Googleアカウントでログイン
3. 「Create API Key」でキーを作成
4. キーをコピー
5. アプリの上部「APIキー設定」で入力

## 🎯 機能別使い方

### 1. 📄 LPスクショ + Gemini文字起こし
**用途**: Webページの全体をスクリーンショットして文字を抽出

**手順**:
1. 「LPスクショ + Gemini」タブを選択
2. URLを入力（例: `https://example.com`）
3. 「📸 スクショを撮影」をクリック
4. スクリーンショットの品質を確認
5. 「✅ このスクショで文字起こし」をクリック
6. 結果が表示されます

### 2. 🎵 音声文字起こし
**用途**: 音声ファイルを文字起こし（97倍速！）

**手順**:
1. 「音声→文字起こし」タブを選択
2. 音声ファイルをドラッグ&ドロップ
3. 「▶ 文字起こしを実行」をクリック
4. 処理完了後、テキストエリアに結果が表示
5. 「📋 テキストをコピー」でコピー可能

**対応フォーマット**: mp3, wav, m4a, aac, ogg, flac, mp4, webm
**最大ファイルサイズ**: 500MB

### 3. 🌐 UTAGE/Loom/スタエフ文字起こし
**用途**: 動画URLから直接文字起こし

**手順**:
1. 「UTAGE/Loom/スタエフ文字起こし」タブを選択
2. URLを入力（改行で複数可能）
   - UTAGE: `.m3u8`のURL
   - Loom: `https://luna.loom.com/...` または `https://www.loom.com/share/...`
   - スタンドFM: `https://cdncf.stand.fm/audios/xxxx.m4a`
3. 「▶ ダウンロード→文字起こし」をクリック
4. 結果が表示されます

### 4. 🎬 動画文字起こし
**用途**: 動画ファイルから音声を抽出して文字起こし

**手順**:
1. 「動画→高速文字起こし」タブを選択
2. 動画ファイルをドラッグ&ドロップ
3. 「▶ 動画から文字起こし」をクリック
4. 音声が抽出され、文字起こしが実行されます

**対応フォーマット**: mp4, mov, m4v, webm, mkv

## 🐛 トラブルシューティング

### ❌ アプリが起動しない
**症状**: ブラウザで http://127.0.0.1:7860 にアクセスできない

**解決策**:
1. ターミナルでエラーメッセージを確認
2. 以下のコマンドで再起動：
   ```cmd
   cd "C:\Users\chatg\Obsidian Vault\papa\文字起こしブースター\mioji_share_v2.1"
   venv\Scripts\activate
   python -m app.main
   ```

### ❌ "ffmpegが見つかりません"
**症状**: 音声・動画処理でエラーが発生

**解決策**:
1. **Windows**でffmpegをインストール：
   ```cmd
   winget install ffmpeg
   ```
2. インストール後、ターミナルを再起動
3. アプリを再起動

### ❌ "APIキーが無効です"
**症状**: APIキーを設定してもエラーが発生

**解決策**:
1. Groq API Key: `gsk_`で始まる正しいキーか確認
2. Gemini API Key: [Google AI Studio](https://aistudio.google.com/app/apikey)で再取得
3. キーにスペースや改行が入っていないか確認

### ❌ ファイルがアップロードできない
**症状**: 音声・動画ファイルをドラッグ&ドロップしても反応しない

**解決策**:
1. 対応フォーマットか確認（mp3, wav, m4a, mp4, mov等）
2. ファイルサイズが500MB以下か確認
3. ブラウザを再読み込み

## ❓ よくある質問

### Q: 無料で使えますか？
A: はい、アプリ自体は無料です。ただし、以下のAPIキーが必要です：
- Groq API Key（無料枠あり）
- Google AI Studio API Key（無料枠あり）

### Q: どのくらい速く文字起こしできますか？
A: 53分の音声を32秒で処理（97.8倍速！）の実績があります。

### Q: 対応しているファイル形式は？
A: 
- **音声**: mp3, wav, m4a, aac, ogg, flac
- **動画**: mp4, mov, m4v, webm, mkv
- **URL**: UTAGE, Loom, スタンドFM

### Q: 大容量ファイルは処理できますか？
A: 最大500MBまでのファイルを処理可能です。

### Q: 日本語の文字起こしは正確ですか？
A: Groq Whisperは日本語に最適化されており、高い精度で文字起こしできます。

### Q: アプリを終了するには？
A: ターミナルで `Ctrl + C` を押すか、ターミナルウィンドウを閉じます。
