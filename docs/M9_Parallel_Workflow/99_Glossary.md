# 初心者向け「超訳」用語集 (Glossary)

## 📚 基本編

| 用語 | エンジニア的定義 | **超訳 (初心者向け)** |
|------|----------------|---------------------|
| **Code (コード)** | プログラミング言語で書かれた命令文 | **AIへの「手紙」**。または料理のレシピ。 |
| **Bug (バグ)** | プログラムの不具合・誤り | **レシピの書き間違い**。またはAIの勘違い。 |
| **Prompt (プロンプト)** | AIへの入力・指示 | **お願い事**。具体的であるほど良い。 |
| **Deploy (デプロイ)** | 本番環境へ反映・公開すること | **開店オープン**。作ったものを世界に見せること。 |

## 🛠 ツール・仕組み編

| 用語 | エンジニア的定義 | **超訳 (初心者向け)** |
|------|----------------|---------------------|
| **Repository (リポジトリ)** | ファイルや変更履歴の保管場所 | **プロジェクト専用のフォルダ**。タイムマシン機能付き。 |
| **Commit (コミット)** | 変更を記録・保存すること | **セーブポイントを作る**。ゲームのセーブと同じ。 |
| **Push (プッシュ)** | ローカルの変更をリモートへ送信 | **アップロード**。手元の作業を倉庫に送る。 |
| **Pull (プル)** | リモートの変更をローカルへ取得 | **ダウンロード**。倉庫から最新版を持ってくる。 |
| **Branch (ブランチ)** | 履歴の流れを分岐させること | **平行世界を作る**。本編に影響を与えずに実験できる場所。 |
| **Merge (マージ)** | 分岐した履歴を統合すること | **世界線の統合**。実験結果を本編に取り込むこと。 |
| **PR (プルリクリエスト)** | マージを依頼すること | **「これでどう？」と確認に出すこと**。採用されるとマージされる。 |

## 💡 AI開発編

| 用語 | エンジニア的定義 | **超訳 (初心者向け)** |
|------|----------------|---------------------|
| **Hallucination (ハルシネーション)** | AIがもっともらしい嘘をつくこと | **AIの「知ったかぶり」**。たまに平気で嘘をつくので注意。 |
| **Context (コンテキスト)** | 文脈、前後の情報 | **話の流れ**。これを忘れるとAIはトンチンカンな返事をする。 |
| **Refactoring (リファクタリング)** | 外部動作を変えずに内部構造を整理 | **大掃除**。見た目は変わらないけど、中身をスッキリさせる。 |
