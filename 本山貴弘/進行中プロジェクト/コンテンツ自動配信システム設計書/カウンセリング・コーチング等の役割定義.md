# カウンセリング・コーチング等の役割定義

対人支援における4つの手法は、相手の状態や目的によって使い分ける必要がある。

| 手法 | 定義・アプローチ | 対象の状態 |
| :--- | :--- | :--- |
| **カウンセリング** | **傾聴**。<br>理想の状態を聞き出し、現状との整理を行う。<br>キーワード＋5W1Hで深堀りする。 | 悩みがある、整理できていない |
| **コーチング** | **引き出す**。<br>質問を通じて、相手の中に眠っている答えを顕在化させる。 | 答えは持っているが、気づいていない |
| **ティーチング** | **教える**。<br>先生と生徒の関係。答えを提示する。 | 知識がない、知らない |
| **コンサルティング** | **解決する**。<br>問題を整理し、相手のリソースを使って解決策を提示・実行支援する。 | 課題解決を求めている |
