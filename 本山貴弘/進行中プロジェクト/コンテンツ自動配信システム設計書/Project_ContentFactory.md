# Project: Content Factory (コンテンツ自動製造システム)

**「情報収集」から「SNS投稿作成・配信」までを完全自動化するシステムの設計書です。**
Gemini (AI) と GAS (Google Apps Script) を連携させ、あなたの脳を使わずに高品質な投稿を量産するラインを構築します。

## 1. システム全体像 (Workflow)

```mermaid
graph TD
    subgraph Input [情報源の入力]
        A[メルマガ / Web記事 / 日々の気づき] -->|コピペ or 転送| B(スプレッドシート<br>「ネタ帳」シート)
    end

    subgraph Processing [AI加工工場 (GAS)]
        B -->|GASトリガー| C{Gemini API<br>(AIプロンプト処理)}
        C -->|変換: Threads用| D[スプレッドシート<br>「ドラフト」列に書き出し]
        C -->|変換: X (Twitter)用| D
        C -->|変換: Note用| D
    end

    subgraph Output [自動配信]
        D -->|連携| E[SNS自動配信ツール<br>(Buffer / SocialDog等)]
        E --> F((各SNSへ投稿))
    end
```

## 2. システム構成要素

### ① スプレッドシート (司令塔)
情報の「入口」と「出口」を管理します。

*   **シート構成**:
    *   **Inputシート**: 「ネタ元」を入れる場所。
        *   A列: **ソーステキスト** (メルマガ本文やURL)
        *   B列: **インサイトメモ** (自分の感想など、あれば)
        *   C列: **ステータス** (未処理 / 処理済)
    *   **Outputシート**: AIが生成した投稿案が吐き出される場所。
        *   A列: **Threads用原稿**
        *   B列: **X用原稿**
        *   C列: **Note用原稿**
        *   D列: **配信予定日**

### ② GAS × Gemini API (頭脳)
「Gems」で行っているような変換処理を、スクリプト内で自動実行させます。

*   **機能**:
    *   Inputシートに新しい行が追加されたら検知。
    *   そのテキストを読み取り、Google Gemini API (Flashモデル等) に投げる。
    *   **「あなたはプロのSNSマーケターです。以下の文章を元に…」** というプロンプトを含めてリクエスト。
    *   返ってきた回答をお行儀よくOutputシートに書き込む。

### ③ SNS自動配信ツールとの連携
ここは「どのツールを使うか」で接続方法が変わります。

*   **案A: CSVインポート連携 (確実・簡単)**
    *   Outputシートの内容をCSVとして書き出し、ツールに読み込ませる。
*   **案B: API / メール連携 (全自動)**
    *   もし配信ツールに「メールで投稿予約できる機能」があれば、GASからメールを送るだけで完了します。
    *   (Buffer等はZapierを介すとスムーズです)

## 3. 開発ロードマップ

### Phase 1: 基盤構築 (スプシ + GAS)
*   [ ] スプレッドシートの枠組み作成。
*   [ ] Gemini APIキーの取得。
*   [ ] GASで「セルに入力されたらAIが回答して隣のセルに返す」テスト実装。

### Phase 2: AIプロンプトの移植 (Brain)
*   [ ] 現在Gemsで想定している「Threads用」「X用」のスタイル定義をGASに組み込む。
*   [ ] 複数のアウトプット (長文、短文など) を一度に生成できるようにする。

### Phase 3: パイプライン完成 (Automation)
*   [ ] 生成されたテキストを配信ツール用フォーマットに整える。
*   [ ] 運用テスト (ネタを入れてから投稿予約されるまでのフロー確認)。
