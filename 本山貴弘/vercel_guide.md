# Vercel（バーセル）とは？：初心者向けガイド

## 1. Vercelの概要
Vercelは、作成したWebサイト（HTML, CSS, JavaScriptなど）を**世界中に公開するための「プラットフォーム（置き場所）」**です。
本来、Webサイトを公開するには「レンタルサーバーの契約」「ドメインの設定」「ファイルのアップロード」などの複雑な手順が必要ですが、Vercelはこれらを**数クリックで、しかも無料**で行えるのが最大の特徴です。

## 2. 主な特徴・メリット

### ① 驚異的な手軽さ
*   **「ドラッグ＆ドロップ」で公開**: 難しいコマンド操作は不要です（後述）。GitHubなどのツールと連携すれば、ファイルを保存するだけで勝手に更新されます。
*   **設定不要**: 面倒なサーバー設定やSSL（セキュリティ鍵）の設定を自動でやってくれます。

### ② 高速な表示速度
*   **世界中のサーバーに配信**: CDN（コンテンツデリバリネットワーク）という仕組みを標準装備しており、日本だけでなく世界中どこからアクセスしても爆速で表示されます。
*   これも設定不要で、勝手に最適化されます。

### ③ 無料で使える（Hobbyプラン）
*   個人のポートフォリオや小規模な商用サイトなら、基本的に**ずっと無料**で使えます。
*   クレジットカードの登録も不要で始められます。

### ④ 自動でURL発行
*   公開すると `project-name.vercel.app` というURLが即座に発行されます。
*   独自ドメイン（例: `motoyama.com`）を持っている場合も、簡単に紐付け可能です。

## 3. 今回のLP公開での活用イメージ
今回作成した「Business Redesign」のランディングページ（HTML/CSSファイル）を、Vercelにアップロードするだけで、**誰でも見られるURL（本番環境）**として公開できます。

## 4. 公開までの大まかな手順
1.  **アカウント作成**: Vercel公式サイトでアカウントを作る（GitHubアカウント推奨）。
2.  **プロジェクト作成**: 「New Project」ボタンを押す。
3.  **アップロード**: LPのファイルが入ったフォルダ（`ランディングページ`）をVercelに連携（またはドラッグ＆ドロップ）。
4.  **公開完了**: 数秒〜数分でURLが発行され、世界中に公開されます。
