# SNS投稿作成・運用マニュアル

Threads自動投稿システム用のコンテンツを作成する際のルールと手順です。

## 1. 入稿フォーマット (標準)

AIに原稿作成を依頼する際は、以下のフォーマットを指定してください。
この形式であれば、スプレッドシートへの貼り付けがスムーズに行えます。

### 📋 指定プロンプト（AIへの指示用）
> 出力は以下のルールを厳守してください：
> 1. 区切り文字は「| (パイプ)」を使用すること
> 2. 改行コードは使用せず、代わりに `<br>` タグを使用すること
> 3. 列順序: `ID | タイトル | 本文 | 画像URL | 備考`
> 4. コードブロック (`text`形式) で出力すること

### 📝 出力サンプル
```text
TH001|タイトル|本文だよ。<br>改行もこうやって書くよ。||Process
TH002|タイトル2|画像がある場合はURLの列に入れるよ。|https://...|Philosophy
```

---

## 2. スプレッドシートへの登録手順

1.  上記フォーマットで出力されたテキストをコピー。
2.  スプレッドシートの **「IDEAシート」** の **A2セル** を選択して貼り付け。
3.  貼り付け直後にメニューの **「データ > テキストを列に分割」** をクリック。
4.  区切り文字で **「カスタム」** を選び、 **`|`** (パイプ) を入力。

---

## 3. 各列の定義

| 列 | 項目名 | 説明 |
| :--- | :--- | :--- |
| **A** | **ID** | 管理ID（TH001, TH002...）。通し番号でOK。 |
| **B** | **タイトル** | **(重要)** 投稿には反映されません。管理用のメモです。 |
| **C** | **本文** | 実際の投稿内容。`<br>` は自動で改行に変換されます。 |
| **D** | **画像URL** | 画像がある場合のみ入力。なければ空欄。 |
| **E** | **備考** | カテゴリー（Process/Raw Voice等）やメモ書きに使用。 |
