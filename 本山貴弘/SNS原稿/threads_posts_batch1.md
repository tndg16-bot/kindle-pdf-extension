# Threads投稿案 (Batch 1) - スプレッドシート用

## 📋 コピー用データ (確実に列を分ける方法)

タブ区切りでうまくいかない場合、**「記号（|）」で区切ってからスプレッドシートの機能で分割** するのが一番確実です。

### 手順
1.  以下のテキストブロックをすべてコピーします。
2.  スプレッドシートの **A2セル** に貼り付けます（この時点では全部A列に入ってOK）。
3.  貼り付けた直後に、右下に出る「貼り付けのオプション」アイコン、またはメニューの **「データ > テキストを列に分割」** をクリックします。
4.  区切り文字の選択で **「カスタム」** を選び、 **`|`** (縦棒) を入力します。
    *   これできれいに5つの列に分かれます！
