# Nano Banana Pro Prompt Collection

**Source**: [みんなのニュースレター](https://tetumemo.m-newsletter.com/posts/61b43ccee44d5000)

## 1. LINEスタンプ作成
**目的**: キャラクターの一貫性を保ちながら、複数の表情・ポーズを一度に生成する。

```markdown
添付画像のキャラクターをちびキャラにして。LINEスタンプを作成。表情・ポーズ別・セリフ入で12種類。
```

## 2. イラストから漫画化
**目的**: 1枚のイラストからストーリーを「推論」させ、漫画形式にする。

```markdown
このイラストからモノクロの漫画を1ページ推論してください
```

## 3. 食材の可視化 (インフォグラフィック)
**目的**: 原材料から消費までを1枚のポスター風に可視化する。

```markdown
参考画像の食品の原材料の生産、製造加工、調理する過程を可視化。それぞれの過程に従事する人々の姿と努力、最後に喜んで食べる消費者の姿を描き、“食品紹介ポスター”風に仕上げて。
```

## 4. 痛車 (ラッピングカー) 作成
**目的**: 3D的な曲面を理解させた上で、車体にキャラクターを配置する。

```markdown
画像のキャラクターのコスプレイヤーが渋谷スクランブル交差点の中央で、画像のイラストでラッピングされた車と一緒に写っている迫力のある写真を出力してください。※チェック※・看板の文字などは日本語と英語で文字化けをしないように出力してください。
```

## 5. Glowing Contours (光る輪郭)
**目的**: 幻想的なスタイルを指定する。

```markdown
Glowing contours
```
*(※これはスタイル指定としてプロンプトに追加する単語です)*
