# Threads API 設定ガイド (完全版)

GASからThreadsに自動投稿するためには、Meta社から**「User ID」**と**「Access Token」**の2つを取得する必要があります。
手順はやや複雑ですが、この通りに進めれば大丈夫です。

---

## ✅ 事前準備
1.  **Instagramアカウント**（プロアカウント/クリエイターアカウント推奨）
2.  **Facebookページ**（自分用でOK、Instaと連携済みであること）
3.  **Threadsアカウント**（Instaと同じアカウントで開設済みであること）

---

## Step 1: Meta for Developers でアプリ作成

1.  [Meta for Developers](https://developers.facebook.com/) にアクセスし、Facebookアカウントでログイン。
2.  右上の **「マイアプリ」** → **「アプリを作成」** をクリック。
3.  **「その他」** を選択 → 「次へ」。
4.  アプリタイプで **「ビジネス」** を選択 → 「次へ」。
5.  アプリ詳細入力:
    *   アプリ名: `My Threads Scheduler` (何でもOK)
    *   アプリの連絡先メールアドレス: ご自身のメール
    *   ビジネスアカウント: (あれば選択、なければ未選択でOK)
    *   → **「アプリを作成」** をクリック。

## Step 2: Threads API の追加

1.  アプリダッシュボードが開いたら、下の方にある **「Threads API」** を探し、**「設定」** をクリック。
2.  左メニューの **「ユースケース」** (あるいは「製品」設定内) で、アクセス許可を設定します。
    *   必要な権限: `threads_basic`, `threads_content_publish`
    *   これらを「追加」または「設定」します。

## Step 3: テストユーザーの設定

1.  左メニュー **「アプリの役割」** (App Roles) → **「役割」** をクリック。
2.  **「Threads Testers」** (Threadsテスター) セクションを探し、**「テスターを追加」** をクリック。
3.  ご自身の **Instagram (Threads) ID** を入力して検索し、追加します。
4.  **【重要】承認作業**:
    *   Webブラウザで [Threads](https://www.threads.net/) を開き、自分のプロフィールへ。
    *   「設定」→「アカウント」→「ウェブサイトの許可」→「テスターへの招待」へ進み、**「承認」** する。

## Step 4: アクセストークンとユーザーIDの取得

開発者ツールの「グラフAPIエクスプローラ」を使います。

1.  [グラフAPIエクスプローラ](https://developers.facebook.com/tools/explorer/) を開く。
2.  **Metaアプリ**: さっき作ったアプリを選択。
3.  **ユーザーまたはページ**: 「ユーザーアクセストークン」を選択。
4.  **許可 (Permissions)**:
    *   `threads_basic`
    *   `threads_content_publish`
    *   この2つを追加して **「Generate Access Token」** をクリック。
    *   (ポップアップが出たら「OK」で承認)
5.  **アクセストークンの取得**:
    *   表示された長い文字列が **「Access Token」** です。これをコピーして、GASの `THREADS_ACCESS_TOKEN` に貼り付けます。
6.  **ユーザーIDの取得**:
    *   エクスプローラの入力欄（`GET` の横）に `me` と入力して「送信」。
    *   結果として表示される `id` ("123456..."のような数字) が **「User ID」** です。これをGASの `THREADS_USER_ID` に貼り付けます。

---

## ⚠️ 注意点
*   このトークンは「短期トークン」の場合があり、1時間〜数日で切れることがあります。
*   テスト運用中はこれで十分ですが、長期運用時は「長期トークンへの交換」作業が必要になります（まずはテスト投稿成功を目指しましょう）。
