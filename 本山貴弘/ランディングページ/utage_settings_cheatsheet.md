# UTAGE設定値 "カンニングペーパー"
**作成したデザインをUTAGEで再現するための「具体的な設定数値」です。**
迷ったらこの通りに入力してください！

## 1. ヘッダーセクション（一番上の枠）

| 設定項目 | 値（入力する内容） | 備考 |
| :--- | :--- | :--- |
| **背景画像** | `lp_background_clean.png` | 先ほどのフォルダ内の画像 |
| **背景画像のサイズ** | `カバー (Cover)` | 画面いっぱいに広げる設定 |
| **背景位置** | `中央 (Center)` | |
| **上部の余白 (PC)** | `80px` | または `L` か `XL` |
| **下部の余白 (PC)** | `80px` | または `L` か `XL` |

---

## 2. ヘッドライン（見出し文字）

**「会社に頼らず…」の部分**

| 設定項目 | 値（入力する内容） | 備考 |
| :--- | :--- | :--- |
| **文字サイズ (PC)** | `32px` 〜 `36px` | |
| **文字サイズ (スマホ)** | `20px` 〜 `24px` | スマホで大きすぎないように |
| **文字色** | `#1a1a1a` (ほぼ黒) | または `黒` |
| **背景色** | `rgba(255,255,255,0.7)` | **「白」** を選んで **「透明度」** を70%くらいにする |
| **角丸** | `8px` | 少し丸める |
| **影 (ドロップシャドウ)** | `あり` | 薄い影をつけると読みやすい |

---

## 3. 申し込みボタン

**「今すぐ無料で受け取る」ボタン**

| 設定項目 | 値（入力する内容） | 備考 |
| :--- | :--- | :--- |
| **背景色 (グラデーション)** | `#ff9800` (上) → `#f57c00` (下) | **「オレンジ」** 系ならOK！ |
| **文字色** | `#ffffff` (白) | |
| **文字サイズ** | `22px` | |
| **角丸** | `50px` | 丸いボタンにする場合 |
| **影 (Box Shadow)** | `あり` | ボタンを目立たせる |
| **サブテキスト** | `※登録解除はいつでも可能です` | ボタンの下に小さく文字を入れる機能があれば |

---

## 4. 本文エリア

| 設定項目 | 値（入力する内容） | 備考 |
| :--- | :--- | :--- |
| **背景色** | `#f9f9f9` (薄いグレー) | 真っ白ではなく少し色をつける |
| **枠線 (ボーダー)** | `#eeeeee` | 薄いグレーの線 |
