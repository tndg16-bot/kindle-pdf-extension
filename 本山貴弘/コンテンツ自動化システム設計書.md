# コンテンツ自動配信システム設計書

Gemini Gems等で作成した投稿案をスプレッドシートで管理し、GAS (Google Apps Script) を使って各SNSへ自動配信するシステムの構築手順書です。

## 1. システム全体像

```
[Gemini Gems (ネタ出し)]
       ↓ (コピペ)
[スプレッドシート (司令塔)]
  ├ ネタ帳シート (A/B/C)
  └ カレンダーシート (配信予約)
       ↓ (GASで定期チェック)
[Google Apps Script]
       ↓ (API連携)
[各SNSプラットフォーム]
  ├ X (旧Twitter)
  ├ Instagram (フィード)
  └ Threads
```

## 2. スプレッドシートの構築

新規にGoogleスプレッドシートを作成し、以下の4つのシートを用意してください。

### ① シート名: `DASHBOARD` (カレンダー配信予約)
配信スケジュールを俯瞰・管理するメイン画面です。

| 行/列 | A | B | C | D | E |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **1** | **予約日時** | **プラットフォーム** | **カテゴリー** | **投稿内容(参照)** | **ステータス** |
| **2** | 2024/01/01 18:00 | X | A | (数式で参照) | 予約済 |
| **3** | 2024/01/02 20:00 | Threads | B | (数式で参照) | 送信済 |

*   **ステータス列**: 「予約済」「送信済」「エラー」で管理。

### ②〜④ シート名: `IDEA_A`, `IDEA_B`, `IDEA_C` (ネタ帳)
カテゴリーごとのネタストック場所です。

| 行/列 | A | B | C | D |
| :--- | :--- | :--- | :--- | :--- |
| **1** | **ID** | **タイトル** | **本文** | **画像URL** |
| **2** | A001 | 思考の罠 | 本文テキスト... | https://... |

## 3. GAS (スクリプト) の設定手順

1.  スプレッドシートのメニューから「拡張機能」→「Apps Script」を開く。
2.  エディタが開くので、`コード.gs` ファイルの中身を全て消し、配布した `social_media_manager.js` のコードを貼り付ける。
3.  **APIキーの設定**:
    *   スクリプトの先頭にある `CONFIG` 定数部分に、各SNSのAPIキーやトークンを入力する（取得方法は後述）。
4.  **トリガー設定**:
    *   左メニュー「トリガー(時計アイコン)」→「トリガーを追加」。
    *   実行する関数: `main`
    *   イベントのソース: `時間主導型`
    *   タイプ: `分ベースのタイマー` → `15分おき`（または1時間おき）

## 4. 各SNSのAPI取得（難易度：高）
自動投稿には各サービスの「開発者登録」が必要です。これが一番のハードルとなります。

*   **X (Twitter)**:
    *   Twitter Developer Portal でプロジェクト作成。
    *   API Key, API Secret, Access Token, Access Token Secret を取得。
    *   ※Freeプラン（無料）は月1,500件まで投稿のみ可能。

*   **Instagram & Threads**:
    *   Meta for Developers でアプリ作成。
    *   Instagram Graph API と Threads API を設定。
    *   アクセストークンを取得（有効期限があるため、長期運用の場合は更新処理が必要）。

## 5. Noteについて
*   **注意**: Noteは現在、一般ユーザー向けの「記事投稿API」を公開していません。
*   **対策**: スプレッドシートで「下書き」まで管理し、投稿は手動（コピペ）で行う運用を推奨します。または、Noteの「メール投稿機能」があればそれを使いますが、現在は非推奨機能となっている場合が多いです。
