# プロジェクト登録テンプレート

## 基本テンプレート

```markdown
## プロジェクト登録依頼

**プロジェクト名**: [プロジェクト名]

**目的**: 
[このプロジェクトで達成したいこと]

**背景**: 
[なぜこれをやりたいのか]

**サブタスク**:
- [ ] タスク1
- [ ] タスク2
- [ ] タスク3
- [ ] タスク4
- [ ] タスク5

**ラベル**: coaching / ai-business / infra / portfolio
```

---

## 例：コーチング関連

```markdown
## プロジェクト登録依頼

**プロジェクト名**: オンラインコミュニティ「アンデス」構築

**目的**: 
「人生の自己決定」をテーマにしたオンラインコミュニティを立ち上げる

**背景**: 
個別セッションだけでなく、継続的なコミュニティでの学びを提供したい

**サブタスク**:
- [ ] コンセプト設計・言語化
- [ ] LP（ランディングページ）作成
- [ ] Discord/Slack設計
- [ ] 料金体系決定
- [ ] モニター募集
- [ ] 初期メンバー招待

**ラベル**: coaching
```

## 例：AI副業関連

```markdown
## プロジェクト登録依頼

**プロジェクト名**: AI活用マニュアル販売

**目的**: 
初月10万達成のノウハウをマニュアル化して販売する

**背景**: 
自身の成功体験を再現性のある形で提供したい

**サブタスク**:
- [ ] コンテンツ構成決定
- [ ] 原稿執筆
- [ ] デザイン作成
- [ ] 販売プラットフォーム選定（Note/Brain等）
- [ ] 価格設定
- [ ] 告知・販売開始

**ラベル**: ai-business
```

## 例：インフラ関連

```markdown
## プロジェクト登録依頼

**プロジェクト名**: 自動デプロイパイプライン構築

**目的**: 
GitHub push → 自動テスト → Vercel デプロイの完全自動化

**背景**: 
手動デプロイの手間を削減し、開発効率を上げたい

**サブタスク**:
- [ ] GitHub Actions 設定
- [ ] テストスクリプト作成
- [ ] Vercel連携設定
- [ ] 動作確認
- [ ] ドキュメント化

**ラベル**: infra
```

---

## 使い方

1. 上記テンプレートをコピーして埋める
2. Antigravityに渡す
3. 壁打ちでタスクを調整
4. `/new-project` ワークフローでGitHubに登録
