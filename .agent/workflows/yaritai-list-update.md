# やりたいことリスト追加ワークフロー

このワークフローは、ユーザーが「やりたいことリストに追加して」と指示した際に、適切な形式で `本山貴裕/やりたいことリスト.md` を更新するための手順です。

---

## ファイル構造

やりたいことリストは以下の3層構造で管理されています：

### 📊 上部: プロジェクト進捗サマリー (Dashboard)
```markdown
## 📊 プロジェクト進捗サマリー (Dashboard)

| 項目 | 数 |
|------|-----|
| **合計** | X |
| **✅ 完了** | X |
| **🔄 進行中** | X |
| **⚪ 未着手** | X |
```

### 📋 中段: プロジェクト一覧 (Projects)
各プロジェクトは `M番号` で識別され、ステータスは以下の形式で管理：
- `[ ]` = 未着手
- `[/]` = 進行中（ステータスのみ）
- `[X/Y]` = 進行中（X/Y タスク完了）
- `[x]` = 完了

```markdown
### カテゴリ名
- [ステータス] **M番号: プロジェクト名**
    - プロジェクトの簡易説明
```

### 📝 下段: プロジェクト詳細 (Details)
各プロジェクトの詳細は `## 📝 プロジェクト詳細` セクション内に記載：

```markdown
## 📝 プロジェクト詳細

### M1: プロジェクト名
- **ステータス**: 進行中 (3/10)
- **担当エージェント**: Antigravity, Codex
- **開始日**: 2026-01-05
- **目標完了日**: 2026-01-20

#### タスクリスト
- [x] タスク1
- [/] タスク2（進行中）
- [ ] タスク3

#### メモ・備考
- 補足情報など
```

---

## 追加ルール

### 1. 新しいアイデアを追加する場合
ユーザーが「これをやりたいことリストに追加して」と言った場合：

1. **中段（プロジェクト一覧）** に新しい M番号で追加
   - 適切なカテゴリに配置
   - ステータスは `[ ]`（未着手）で開始
   - 次のM番号を割り当て（M10, M11, ...）

2. **上部（サマリー）** を更新
   - 合計を +1
   - 未着手を +1

3. **下段（詳細）** にテンプレートを追加（必要に応じて）

### 2. プロジェクトを開始する場合
1. 中段のステータスを `[ ]` → `[/]` または `[0/X]` に変更
2. サマリーの「未着手」を -1、「進行中」を +1

### 3. プロジェクトを完了する場合
1. 中段のステータスを `[x]` に変更
2. サマリーの「進行中」を -1、「完了」を +1
3. `## ✅ やったことリスト` セクションにも成果を追記

### 4. 壁打ちメモを追加する場合
`## 💭 壁打ちメモ・アイデア` セクションに追記

## 実行例

**ユーザー**: 「Noteでの発信を始めたいんだけど、やりたいことリストに追加して」

**Antigravityの対応**:
1. 中段に追加:
```markdown
- [ ] **M10: Noteでの権威性確立プロジェクト**
    - 「外部依存からの脱却」をテーマにした連載記事の企画・執筆
```

2. サマリー更新: 合計+1, 未着手+1

3. 詳細セクションに追加（オプション）:
```markdown
### M10: Noteでの権威性確立プロジェクト
- **ステータス**: 未着手
- **担当エージェント**: Antigravity（記事構成）, Local AI（下書き生成）
- **目標**: 月4本の記事投稿

#### タスクリスト
- [ ] テーマ・ターゲット設定
- [ ] 記事構成案の作成
- [ ] 初回記事の執筆
```
