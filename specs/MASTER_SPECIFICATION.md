# 🦁 ゲーミファイド曼荼羅チャート - マスター仕様書 (Master Specification)
**Version**: 1.0 (Japanese)
**Last Updated**: 2026-01-04
**MVP Deadline**: 2026-01-05 (Target)

## 1. コアコンセプト
*   **ビジョン**: 仕事を始める「トリガー」となり、前進感と達成感を得られるアプリ。
*   **メタファー**: 赤ちゃんタイガーを育て、神獣へと進化させる。
    *   **進化パス**: 赤ちゃん ➔ 子タイガー ➔ 親タイガー ➔ 神獣/霊獣。
*   **リアル報酬**: 「プチ贅沢（サウナ、ジム、美味しいご飯）」への許可証。

## 2. 機能要件 (MVPスコープ)

### 2.1 曼荼羅チャート (Mandala Chart)
*   **構造**: 3階層 (Vision ➔ Area/Means ➔ SubTasks)。
*   **デザイン**: 「ストイック・シンプル（大谷翔平スタイル）」を基調としつつ、タイガーなどの「ポップ」な要素を加える。
*   **背景**: MVPでは「動的で美しい自然風景（クリアな景色）」を採用。

### 2.2 看板ボード (Kanban Board)
*   **表示対象**: レベル3（サブタスク）のみ表示。
*   **フィルタリング機能 (必須)**:
    *   **期間**: 今日やる / 今週やる / 今月やる。
    *   **カテゴリ**: 曼荼羅のエリア（Level 1/2）で絞り込み。
*   **完了タスク**: 画面からは消さず「完了ログ」として残すが、視認性を妨げないデザインにする。
*   **サウンド (SFX)**:
    *   タスク完了時: **あり**。
    *   レベルアップ時: **あり**。

### 2.3 ゲーミフィケーション・エンジン
*   **XPシステム**:
    *   難易度別固定 (S=100, A=50, B=20, C=5)。軽快さを重視。
    *   ペナルティ: 未完了に戻すと -10 XP。
*   **進化トリガー**: **レベル10到達** で次の形態へ進化。
*   **報酬**: 進化演出 ＋ 「サウナに行ってよし！」等のメッセージ表示。

### 2.4 データ & 技術スタック (Technical Shift)
*   **アーキテクチャ**: クラウド型Webアプリ。
*   **構成**: Next.js + **Firebase (Firestore/Auth)** + Vercel。
*   **理由**: PCだけでなく、Android（Webブラウザ）からもアクセスして同期するため。
*   **認証**: Googleログイン、またはEmail認証。

### 2.5 Obsidian連携
*   **現状**: 片方向インポート (Markdown ➔ App)。
*   **将来 (Post-MVP)**: 双方向同期。アプリで完了したらObsidian側も完了にする。
*   **エクスポート**: 曼荼羅の状態をMarkdown/PDFとして書き出す機能（MVP要件）。

## 3. UI/UX方針
*   **デバイス**: PCファーストだが、スマホ（Androidブラウザ）でも崩れないこと。
*   **インタラクション**: クリック時に心地よいフィードバック（音・エフェクト）。

## 4. MVP達成条件 (1/5目標)
1.  **Web公開**: Vercelデプロイ済みで、URLからアクセス可能。
2.  **認証**: ユーザーごとのデータ保存 (Firebase Auth)。
3.  **タスク管理**: 曼荼羅 ⇔ 看板 (サブタスク) の完全連携。
4.  **フィルタリング**: 看板での期間・カテゴリ絞り込み。
5.  **ゲーミフィケーション**: XP加算、レベルアップ、基本進化（画像切り替え）。
6.  **エクスポート**: PDF/Markdown出力。
