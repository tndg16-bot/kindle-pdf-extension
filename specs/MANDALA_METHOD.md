# 🎯 Mandala Chart Methodology (Ohtani Style)

## 1. Structure (Since 1979)
The Mandala Chart is a 3x3 matrix planning tool (total 81 squares).
*   **Core (Center)**: The Ultimate Goal (Main Theme).
*   **Surrounding 8 (Sub-Goals)**: The 8 elements required to achieve the Core.
*   **Outer 64 (Actions)**: The specific actions required to achieve each Sub-Goal.

### Layout Logic
The 3x3 grid is arranged as follows:
```
[4]  [5]  [6]
[3] CORE  [7]
[2]  [1]  [8]
```
*(There is no strict numbering rule, but placing the Core in the exact center is mandatory.)*

## 2. Best Practices (Shohei Ohtani Example)
Ohtani used this in High School to set his goal: "Draft No.1 by 8 Teams".

### Step 1: Define the Core
*   **Goal**: ドラフト1位 8球団 (Draft No.1)

### Step 2: Define 8 Elements (Sub-Goals)
He identified 8 pillars needed for this:
1.  **体づくり (Body)**
2.  **コントロール (Control)**
3.  **キレ (Sharpness)**
4.  **スピード160km (Speed)**
5.  **変化球 (Breaking Ball)**
6.  **運 (Luck)** - *Unique Insight!*
7.  **人間性 (Humanity)**
8.  **メンタル (Mental)**

### Step 3: Define 64 Actions
For "Luck", he listed: "Greeting", "Cleaning", "Reading", "Support Referees".
For "Humanity", he listed: "Loved by others", "Planning", "Grateful".

**Key Takeaway**: A Mandala Chart is not just a todo list. It is a **Balance Sheet of Success**.
Ideally, you grow in all 8 directions to support the Core.

## 3. How to Use in "Gamified Tiger"
*   **Center**: Your Life Vision.
*   **8 Pillars**: Identify the 8 areas (Health, Wealth, Career, etc.).
*   **Balance**: If you only do "Wealth" tasks, your Tiger becomes unbalanced (Cloudy).
