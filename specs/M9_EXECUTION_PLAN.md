## 🚀 並列実行タスク一覧 (Parallel Execution Tasks)

全てのラインを同時に動かします。

### Track A: 開発ガイドライン (担当: Antigravity, Codex)
最優先でエンジニアチーム（おもに自分たち）が使うためのコアガイドラインを策定。
- [ ] **A-1**: Web → GitHub → Chat → Local フローの詳細手順化
- [ ] **A-2**: エラー発生時のトラブルシューティングフロー
- [ ] **A-3**: コミットメッセージとPRのルール定義

### Track B: 初心者向け教育コンテンツ (担当: Leo, Sage)
非エンジニアでも理解できる「概念」の言語化。
- [ ] **B-1**: 教科書「AIとペアプログラミングする未来」の目次構成
- [ ] **B-2**: 専門用語（Git, PR, Deploy等）の「超わかりやすい」比喩表現集
- [ ] **B-3**: 研修カリキュラム「1時間で体験するAI開発」のシナリオ作成

### Track C: プレゼンテーション資料 (担当: Mia)
視覚的に理解させるためのスライド資料。
- [ ] **C-1**: スライド全体のストーリーライン作成（起承転結）
