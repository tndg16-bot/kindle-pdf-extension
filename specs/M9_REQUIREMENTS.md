## 🔄 ワークフロー定義

### 基本フロー
```
Web開始 → GitHub確認 → Chat指摘 → ローカルハンドライティング（最終手段）
```

### 詳細フロー
1. **Web開始**: Claude Code Web で初期実装を依頼
2. **GitHub確認**: 自動コミットされたコードを GitHub で確認
3. **Chat指摘**: 問題点があれば Chat で修正を指示
4. **ローカル修正**: どうしても修正できない場合のみローカルで手書き

### 並列実行の原則
- 「並列実行を優先しろ」をメタ指示として常に付与
- 依存関係のないタスクは同時実行を指示
- ツール呼び出しを 1 つずつではなく並列で実行
