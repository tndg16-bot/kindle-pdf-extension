# Next.js + Supabase セットアップマニュアル

このマニュアルは、Next.jsプロジェクトを手動でセットアップし、Supabaseと連携するための手順をまとめたものです。

## 1. Next.js プロジェクトの作成

### 1.1. プロジェクトディレクトリの作成

まず、プロジェクトのルートとなるディレクトリを作成します。

```bash
mkdir my-website
```

### 1.2. Next.js コアファイルの作成

### 1.3. 依存関係のインストール (手動)

Next.jsプロジェクトのディレクトリに移動し、必要な依存関係をインストールします。

1.  **プロジェクトディレクトリに移動:**
    ```bash
    cd my-website
    ```
2.  **依存関係をインストール:**
    ```bash
    npm install
    ```
    *注: このコマンドはご自身のターミナルで実行してください。*

### 1.4. 開発サーバーの起動 (手動)

依存関係のインストールが完了したら、開発サーバーを起動して、ウェブサイトが正しく表示されるか確認します。

```bash
npm run dev
```
*注: このコマンドはご自身のターミナルで実行してください。サーバーは `http://localhost:3000` でアクセスできます。*

## 2. Supabase のセットアップと Next.js との連携

### 2.1. Supabase プロジェクトの作成 (手動)

Supabaseのウェブサイトにアクセスし、新しいプロジェクトを作成します。

*   [Supabaseのウェブサイト](https://supabase.com/) にアクセスし、アカウントを作成またはログインします。
*   新しいプロジェクトを作成します。プロジェクト名、データベースパスワード、リージョンなどを設定します。

### 2.2. API キーの取得 (手動)

作成したSupabaseプロジェクトのダッシュボードから、Next.jsアプリケーションからSupabaseに接続するために必要なAPIキーを取得します。

*   プロジェクトのダッシュボードに移動し、「Project Settings」→「API」セクションにアクセスします。
*   ここに「Project URL」と「`anon` public key」が表示されています。これらを控えておいてください。

### 2.3. 環境変数の設定 (手動)

Next.jsプロジェクトでSupabaseのAPIキーを使用するために、環境変数を設定します。

*   `my-website` ディレクトリのルートに `.env.local` ファイルを作成します。
*   このファイルに、SupabaseのURLと`anon`キーを以下のように記述します。`YOUR_SUPABASE_URL`と`YOUR_SUPABASE_ANON_KEY`は、Supabaseダッシュボードから取得した実際の値に置き換えてください。

    ```
    NEXT_PUBLIC_SUPABASE_URL=YOUR_SUPABASE_URL
    NEXT_PUBLIC_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
    ```
    *注意: `.env.local` ファイルはGitにコミットされないように、`.gitignore` に追加されていることを確認してください。*

### 2.4. Supabase クライアントのインストール (CLI)

Next.jsプロジェクトでSupabaseの機能を利用するために、Supabaseクライアントライブラリをインストールします。

```bash
npm install @supabase/supabase-js
```
*注: このコマンドは `my-website` ディレクトリ内で実行してください。*

### 2.5. Supabase クライアントの初期化 (手動)

Supabaseクライアントを初期化するためのファイルを作成し、アプリケーション全体でSupabaseインスタンスを利用できるようにします。

*   `my-website/lib/supabase.ts` (または `my-website/utils/supabase.ts`) のようなファイルを作成し、以下のコードを追加します。

    ```typescript
    // lib/supabase.ts
    import { createClient } from '@supabase/supabase-js'

    const supabaseUrl = process.env.NEXT_PUBLIC_SUPABASE_URL
    const supabaseAnonKey = process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY

    if (!supabaseUrl || !supabaseAnonKey) {
      throw new Error('Missing Supabase URL or Anon Key')
    }

    export const supabase = createClient(supabaseUrl, supabaseAnonKey)
    ```
