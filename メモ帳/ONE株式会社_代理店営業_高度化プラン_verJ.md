# ONE株式会社 代理店営業 高度化プラン（ジェイ・エイブラハムモデル版）

## 1. 基本方針：事業資産の最大化

本プランは、単発の代理店手数料収入（点）を追うのではなく、ジェイ・エイブラハムのマーケティング哲学に基づき、以下の3つの収益源を戦略的に拡大することで、持続的なキャッシュフロー（面）を構築することを目的とする。

1.  **顧客数の増加:** JV（ジョイントベンチャー）戦略により、他社の信頼を活用し、効率的に新規顧客を獲得する。
2.  **顧客単価の向上:** バックエンド商品を設計し、高付加価値のコンサルティングへ引き上げることで、LTV（生涯顧客価値）を最大化する。
3.  **購入頻度の増加:** 紹介インセンティブと成果報酬型モデルにより、既存顧客との関係を強化し、継続的な収益を生み出す。

---

## 2. USP（独自の強み）とリスクリバーサル

- **再定義されたUSP:**
  > **「AI活用による採用コストの最適化」を専門とする、唯一の人材領域コンサルタント。マイナビ広告の効果を最大化し、採用プロセス全体のROI（投資対効果）を改善します。**

- **リスクリバーサル（顧客のリスクをなくす保証）:**
  > **初回コンサルティング（現状分析・課題特定）は完全無料。ご提案内容にご納得いただけない場合、費用は一切いただきません。さらに、ご契約から3ヶ月以内に採用効率の改善が見られない場合、コンサルティング料は全額返金いたします。**

## 3. 3つのコア戦略

既存の「コンサルティング型営業」を、以下の3つの戦略へと分解・強化する。

### 戦略1：JV（ジョイントベンチャー）パートナー戦略

自身のネットワークだけでリーチできない優良な中小企業へ、最短距離でアクセスする。

- **パートナー候補:**
  - **士業:** 税理士、社労士、中小企業診断士など（助成金や経営改善の流れで協業）
  - **Web制作/マーケティング会社:** 顧客のWebサイトリニューアルやSEO対策の流れで「採用サイト強化」を共同提案
  - **地域の商工会議所や業界団体**
- **提供する価値（パートナーにとってのメリット）:**
  - 既存顧客への付加価値提案（採用課題の解決）による、顧客満足度と契約維持率の向上。
  - 紹介手数料（レベニューシェア）による、新たな収益源の確立。
  - AIやデジタルマーケティングに関する最新情報の提供。
- **アクション:** パートナー候補リストを作成し、「貴社のクライアントの採用課題を、我々の知見で一緒に解決しませんか？」という共同提案を持ちかける。

### 戦略2：バックエンド収益最大化戦略

「マイナビ広告掲載」を入口（フロントエンド商品）と位置づけ、より高単価・高収益なバックエンド商品で利益を最大化する。

- **フロントエンド商品（入口）:**
  - マイナビ求人広告の掲載代理
  - 無料AI活用診断
- **バックエンド商品（本命）:**
  1.  **AI活用・採用DXコンサルティング:** 3ヶ月〜の伴走型プログラム（月額30〜50万円）
  2.  **採用担当者向け・AI活用研修:** 買い切り型の研修パッケージ（1回50万円〜）
  3.  **成果報酬型・採用代行（RPO）:** 採用決定時に年収のX%をいただくモデル
  4.  **採用特化型ウェブサイト/LP制作:** AIチャットボット導入などをセットにした制作プラン

### 戦略3：紹介インセンティブ戦略

満足した顧客が、次の顧客を連れてきてくれる「自動紹介システム」を構築する。

- **仕組み:**
  - 契約顧客に対し、紹介インセンティブプログラムを標準で案内する。
  - **例1:** 「ご紹介いただいた企業様がご成約した場合、貴社の次回の広告掲載料を50%割引いたします」
  - **例2:** 「ご紹介経由でのご成約金額の10%を、キャッシュバックいたします」
- **ポイント:** 紹介を「お願い」するのではなく、相手にも明確なメリットがある「仕組み」として提示する。

## 5. 新たな成功指標（KPI）

従来の「売上」目標に加え、事業の資産価値を測る以下の指標を追跡する。

- **JVパートナー開拓数:** 安定的な紹介元をどれだけ確保できたか。
- **紹介経由の商談化率:** 紹介システムが機能しているか。
- **平均顧客単価（LTV）:** バックエンド商品への引き上げが成功しているか。
- **バックエンド商品比率:** 全売上に占める高収益商品の割合。
