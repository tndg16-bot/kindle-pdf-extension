# CursorでCodex CLIを使うための手順書

## 1. はじめに

このドキュメントは、AI搭載コードエディタ「Cursor」の統合ターミナルで、OpenAIの強力なコーディングエージェント「Codex CLI」を利用するための手順を解説します。

- **Cursor**: VSCodeをベースに、AIによるコード生成・編集・チャット機能を統合した、開発効率を飛躍的に向上させるコードエディタです。
- **Codex CLI**: ターミナル（コマンドライン）上で動作するAIエージェントです。自然言語での指示に基づき、コードの読解、記述、修正、シェルの実行などを自律的に行います。

この2つを組み合わせることで、エディタから離れることなく、対話形式でより高度なコーディング作業を完結させることができます。

## 2. 前提条件

この手順を開始する前に、お使いの環境が以下の条件を満たしていることを確認してください。

- **Cursor**: [公式サイト](https://cursor.com/ja)からダウンロードし、インストール済みであること。
- **Node.js**: `v22` 以上のLTS（推奨版）がインストール済みであること。
  - インストールされていない場合は、[Node.js公式サイト](https://nodejs.org/ja)からダウンロードしてインストールしてください。
  - コマンドプロンプトやPowerShellで `node -v` を実行し、バージョンが表示されることを確認してください。
- **OpenAI APIキー**: Codex CLIの利用にはOpenAIのAPIキーが必要です。
  - [OpenAI Platform](https://platform.openai.com/api-keys)にアクセスし、APIキーを取得してください。取得したキーは安全な場所に保管してください。

## 3. Codex CLIのインストールと設定

### Step 1: Codex CLIのインストール

PowerShellまたはコマンドプロンプトを開き、以下のnpmコマンドを実行してCodex CLIをグローバルにインストールします。

```shell
npm install -g @openai/codex
```

### Step 2: APIキーの設定

インストール後、Codex CLIがOpenAIのAPIを利用できるようにAPIキーを設定します。

PowerShellを開き、以下のコマンドを実行してください。`"your-api-key-here"` の部分を、ご自身で取得したAPIキーに置き換えてください。

```powershell
$env:OPENAI_API_KEY="your-api-key-here"
```

**注意:** この設定は現在のターミナルセッションでのみ有効です。PCを再起動したり、新しいターミナルを開くと再度設定が必要になります。

永続的に設定したい場合は、Windowsの環境変数を編集します。
1.  Windowsの検索で「環境変数を編集」と入力し、「システム環境変数の編集」を開きます。
2.  「環境変数」ボタンをクリックします。
3.  「（ユーザー名）のユーザー環境変数」セクションで「新規」をクリックします。
4.  **変数名**に `OPENAI_API_KEY`、**変数値**にあなたのAPIキーを入力し、「OK」をクリックして閉じます。
5.  この設定を有効にするには、開いているCursorやターミナルをすべて再起動する必要があります。

## 4. Cursorでの基本的な使い方

### Step 1: Cursorでターミナルを開く

CursorはVSCodeベースのため、同じ方法で統合ターミナルを開くことができます。

- **ショートカットキー**: `Ctrl` + ` `` ` (バッククォート)
- **メニューから**: 上部メニューの「ターミナル」 > 「新しいターミナル」

画面下部にターミナルパネルが表示されます。

### Step 2: Codex CLIを起動する

ターミナルが開いたら、作業したいプロジェクトのディレクトリに移動（`cd`コマンド）し、以下のコマンドでCodex CLIを起動します。

```shell
codex
```

これで、Codex CLIとの対話セッションが開始されます。プロンプトが表示されたら、自然言語で指示を入力できます。

**例：プロジェクトの概要を尋ねる**
```
> このプロジェクトの目的と主要な技術スタックを教えてください。
```

### Step 3: プロンプトに指示を含めて起動する

`codex`コマンドに続けて、最初の指示を直接渡すこともできます。

```shell
codex "src/index.js ファイルの役割を3行で説明して。"
```

### Step 4: ファイルや画像を渡す（マルチモーダル機能）

Codex CLIの強力な機能の一つが、ファイルやスクリーンショットを理解する能力です。`-i` または `--include` フラグを使ってファイルを渡します。

**例：UIのスクリーンショットからコードを生成する**
```shell
codex -i "design_screenshot.png" "このデザインを再現するHTMLとCSSを作成してください。"
```

## 5. 実践的な活用コマンド例

Cursorのターミナルから、以下のような実践的な指示を出すことができます。

- **コードの読解と要約**
  ```shell
  codex "lib/auth.py にある authenticate_user 関数のロジックをステップバイステップで解説して。"
  ```

- **機能追加とコード編集**
  ```shell
  codex "userController.js に、ユーザー情報を更新する `updateUser` 関数を追加して。既存の `getUser` を参考に、リクエストボディから `name` と `email` を受け取るようにしてください。"
  ```

- **テストの作成**
  ```shell
  codex "utils/string.js の `formatString` 関数のために、Jestを使ったテストケースを3つ作成してください。"
  ```

- **リファクタリング**
  ```shell
  codex "components/Dashboard.jsx が長すぎるので、UIパーツごとに3つの子コンポーネントに分割してリファクタリングしてください。"
  ```

- **コマンドの実行とデバッグ**
  ```shell
  codex "npm run test を実行して。もしテストが失敗したら、エラー内容を分析して修正案を提示してください。"
  ```

## 6. まとめ

Cursorの高度なAI編集機能と、Codex CLIの自律的なエージェント能力を組み合わせることで、開発ワークフローは劇的に変化します。エディタ内でコーディング、デバッグ、テスト、リファクタリングの大部分をAIとの対話を通じてシームレスに行うことが可能になります。

ぜひこの手順書を参考に、未来のコーディングスタイルを体験してみてください。
