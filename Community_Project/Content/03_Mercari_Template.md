```text
即購入OKです！
```

## 2. 利益を守る！コメント返信テンプレート

### 🗨️ 値下げ交渉が来たとき

#### A. 断る場合（やんわりと）
```text
コメントありがとうございます。
出品したばかりですので、今のところ大幅なお値下げは考えておりません。
ご希望に添えず申し訳ありませんが、現在の価格でご検討いただけますと幸いです。
```

#### B. 少しならOKな場合（着地点を提示）
```text
コメントありがとうございます。
[提示額]までは厳しいですが、[妥協額]円でしたらお値下げ可能です。
変更しておきますので、よろしければそのままご購入ください。（早い者勝ちとなります）
```

#### C. 「〇〇円即決です」と言われたとき
```text
ご検討ありがとうございます。
送料・手数料もございますので、そこまでのお値下げは難しいです。
毎日少しずつ値下げしておりますので、ご納得いただける金額になりましたらご購入ください。
```
